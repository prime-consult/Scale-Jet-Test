# WorkFlex UI

Angular 19 app (`@workflex/frontend`).

From the repository root:

```bash
npm run start:web
```

Or from this folder:

```bash
npm start
```

The app is served at [http://localhost:4200](http://localhost:4200) and proxies `/workflex` to the Spring Boot API on port 8080.

See the repository root `README.md` for the full monorepo setup.
